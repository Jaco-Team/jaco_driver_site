# Jaco Driver Site

Мобильный веб-интерфейс для курьеров Jaco: заказы, карта, расчёт, график, статистика и настройки. Проект работает на Next.js 16 / React 19.

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:3225`. Офлайн-режим проверяйте через `npm run preview:offline`, а не через dev-сервер.

Вся рабочая документация и оглавление находятся в [docs/README.md](./docs/README.md): запуск, архитектура, карта, офлайн-режим, проверки и Docker. Правила для инструментов разработки остаются в [AGENTS.md](./AGENTS.md).
