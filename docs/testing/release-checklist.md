# Релизный чек-лист сайта

Отмечайте пункты только после фактической проверки нужной сборки и окружения.

## Сборка и вход

- [ ] `lint`, `typecheck`, unit-тесты и production build прошли для текущего состояния.
- [ ] Проверены вход, выход, повторный вход, SSO и восстановление пароля; ошибки сервера показываются понятно.
- [ ] Проверены `NEXT_PUBLIC_API_ORIGIN`, proxy/CORS, медиа-адрес и ключи карт для целевого окружения.

## Основные сценарии

- [ ] Список и карта показывают одинаковые актуальные заказы; смена точки и категории не оставляет старые данные.
- [ ] Действия с заказом и подтверждения работают, кнопки защищены от повторного нажатия.
- [ ] Расчёт, график, статистика, настройки и предложения открываются и обрабатывают пустые/ошибочные ответы.
- [ ] Светлая, тёмная и системная темы проверены на узком экране и в браузере ПК; модальные окна, таблицы и уведомления читаемы.

## Офлайн и восстановление связи

- [ ] В production-preview после онлайн-загрузки список, карточки и сохранённая область карты открываются без сети.
- [ ] Без сети нет бесконечных индикаторов и ложных ошибок; недоступные действия отключены, состояние связи понятно.
- [ ] После возврата сети данные обновляются без полной перезагрузки; проверены смена точки, категории и повторный вход.
- [ ] Если карта ранее не сохранялась, приложение показывает понятное отсутствие офлайн-подложки, а не пустой экран.

## Перед публикацией

- [ ] Секретный ключ Tiles API передан серверу, не попал в клиентский bundle или репозиторий.
- [ ] На карте присутствуют обязательные логотип и ссылка на условия Яндекса.
- [ ] Проверены мобильный браузер и хотя бы одно реальное устройство, если менялись касания, клавиатура, скролл или модальные окна.
