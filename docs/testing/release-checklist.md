# Релизный чек-лист сайта

Отмечайте пункты только после фактической проверки нужной сборки и окружения.
Автоматические результаты фиксируются в [журнале проверок](./README.md) и не
заменяют ручной smoke. Локальные сценарии ниже не требуют изменения production
или управления боевыми серверами. Условия публикации в конце — отдельная зона
ответственности выпуска, не дополнительные шаги локального запуска.

## Сборка и вход

- [ ] `lint`, `typecheck`, unit-тесты и production build прошли для текущего состояния.
- [ ] Проверены вход, выход, повторный вход, SSO и восстановление пароля; ошибки сервера показываются понятно.
- [ ] Запоздалый ответ проверки сессии после выхода не возвращает прежнего
      пользователя; после входа в другой аккаунт старый успех или ошибка
      не меняют новую сессию. Обычная проверка сессии и восстановление связи
      продолжают работать.
- [ ] Проверены `NEXT_PUBLIC_API_ORIGIN`, proxy/CORS, медиа-адрес и ключи карт для целевого окружения.

## Основные сценарии

- [ ] Список и карта показывают одинаковые актуальные заказы; смена точки и категории не оставляет старые данные.
- [ ] При быстром переключении кафе или категории А → Б → А старый ответ А
      не заменяет уже полученный свежий список и сохранённый кэш; повторные
      нажатия обновления при медленном ответе продолжают работать.
- [ ] Стрелка обновления без фона и рамки закреплена снизу справа карты и не
      перекрывает лимиты/категории; тёмная в светлой теме и белая в тёмной,
      область нажатия 44 × 44; системная тема учитывается,
      ползунок не влияет на видимость. Без сети кнопка скрыта, только при действии
      с заказом неактивна; обычная загрузка не блокирует нажатие. Обновление
      сохраняет категорию и фильтр. Кнопка в шапке осталась.
- [ ] Выход/смена аккаунта и смена кафе сбрасывают фильтр статусов и закрывают
      модалку; на новой точке видны все статусы, в том числе из офлайн-кэша.
- [ ] Обновление заказов, переходы карта/список/категории, повторный выбор текущего
      кафе и перезагрузка страницы в том же аккаунте сохраняют частичный фильтр.
- [ ] Действия с заказом и подтверждения работают, кнопки защищены от повторного нажатия.
- [ ] Карточка на карте сворачивается нажатием по широкой области вокруг верхней
      полоски или свайпом вниз от неё (от 48 px); движение вверх/вбок, короткий
      или отменённый свайп и прокрутка содержимого не закрывают карточку.
- [ ] Сворачивание проверено в мобильном браузере и мышью: одиночный/отменённый
      заказ и группа по адресу, светлая/тёмная темы, шрифт 26; нижние действия
      доступны, при операции закрытие заблокировано, после закрытия карта реагирует.
- [ ] `map_hints` включает и выключает подсказки заказов за границами карты; `ai_recommend` скрывает и показывает ИИ-подбор в списке и на карте.
- [ ] ИИ-подбор показывает маршрут и нумерованные остановки; взятый рекомендованный заказ получает зелёную отметку, а устаревший результат корректно обновляется или сбрасывается.
- [ ] Пустой результат показывает нижнюю модалку «Подходящих заказов для Вас сейчас нет.», техническая ошибка — красное уведомление без маршрута.
- [ ] Расчёт, график, статистика, настройки и предложения открываются и обрабатывают пустые/ошибочные ответы.
- [ ] Светлая, тёмная и системная темы проверены на узком экране и в браузере ПК; модальные окна, таблицы и уведомления читаемы.

### Предложения

- [ ] Выбранные изображения видны до отправки; можно добавить следующую группу,
      удалить одно вложение и закрыть форму без сохранения черновика.
- [ ] Предложение с кавычками, обычным Unicode и `😀🔥👍` создаётся без ошибки,
      а после повторного открытия текст отображается буквально.
- [ ] Карточка показывает все URL из `images` с fallback на старое поле `link`;
      изображения загружаются лениво, открываются полностью, а ошибка загрузки
      имеет понятное состояние и повторную попытку.
- [ ] Сквозной smoke с четырьмя изображениями выполнен против целевого backend;
      после обновления страницы доступны все четыре изображения.

## Офлайн и восстановление связи

### Локальный preview и скачивание карты

- [ ] `npm run preview:offline` использует тот же локальный API, что и `dev`;
      вход и запросы API не блокируются CSP. Проверены сборка и адрес API после
      изменения env, без изменения production-настроек.
- [ ] В `dev` город скачивается при доступном API; в preview скачанный город,
      ранее загруженные страницы и заказы открываются после отключения сети.
- [ ] На медленном локальном API проверена отдельная 12-секундная проверка
      перед скачиванием. После `502` показана понятная ошибка, пакет не отмечен
      готовым, повторная попытка доступна; успешный вход с локальным лимитом
      45 секунд не считается успешной проверкой скачивания.
- [ ] После восстановления API повторно проверены скачивание, пауза,
      продолжение и прерванная загрузка. Задержки не считаются исправленными
      только по успешной сборке preview или перезапуску backend.
- [ ] Переключение `dev` ↔ `preview:offline` не удаляет скачанные городские
      тайлы; после возврата в preview онлайн загружены актуальные страницы
      и активирован актуальный service worker, затем повторена проверка без сети.

### Сброс настроек

- [ ] Кнопка под «Сохранить» открывает подтверждение; отмена/фон не меняют
      черновик и не сохраняют настройки.
- [ ] «Сбросить и сохранить» отправляет один запрос, применяет согласованный
      пресет и закрывает модалку; после перезагрузки значения сохраняются.
- [ ] Системная тема и второе оформление проверены на светлом и тёмном устройстве;
      отменённые заказы — 30 минут, шрифт — 16, размер значков — 1,0.
- [ ] Кафе, сохранённый цвет курьера, фильтр статусов и скачанные карты сохраняются;
      несохранённый выбор цвета не подменяет сохранённый цвет.
- [ ] Без сети кнопки сброса и подтверждения неактивны. При ошибке сохранения
      настройки/черновик не заменяются, можно повторить или отменить.
- [ ] Повторное нажатие и сохранение во время сброса не дублируют запрос;
      запоздалая загрузка и ответ прежней сессии не меняют результат сброса.
- [ ] При шрифте 26 и небольшой высоте модалка прокручивается; действия доступны
      и не перекрывают безопасную нижнюю область.

### Восстановление связи

- [ ] В production-preview после онлайн-загрузки список, карточки и сохранённая область карты открываются без сети.
- [ ] Без сети нет бесконечных индикаторов и ложных ошибок; недоступные действия отключены, состояние связи понятно.
- [ ] После возврата сети данные обновляются без полной перезагрузки; проверены смена точки, категории и повторный вход.
- [ ] Если карта ранее не сохранялась, приложение показывает понятное отсутствие офлайн-подложки, а не пустой экран.

## Перед публикацией

- [ ] Секретный ключ Tiles API передан серверу, не попал в клиентский bundle или репозиторий.
- [ ] На карте присутствуют обязательные логотип и ссылка на условия Яндекса.
- [ ] Проверено право скрывать «Открыть в Картах» по договору/согласованию
      с Яндексом; общие условия требуют её показывать. Техническая опция
      `suppressMapOpenBlock` не заменяет эту проверку.
- [ ] Проверены мобильный браузер и хотя бы одно реальное устройство, если менялись касания, клавиатура, скролл или модальные окна.
