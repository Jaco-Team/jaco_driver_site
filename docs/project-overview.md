# Обзор проекта

`jaco_driver_site` — мобильный веб-интерфейс для курьеров и операционного персонала Jaco. Основные сценарии: вход и восстановление доступа, список и карта заказов, расчёт, график работы, статистика, настройки и предложения. Интерфейс проектируется прежде всего для телефона: короткие подписи, крупные зоны нажатия, минимум визуального шума.

## Стек

- Next.js 16 с Pages Router и React 19;
- MUI 9, SCSS, общие токены в [`shared/styles`](../shared/styles);
- Zustand для состояния, Axios для HTTP-запросов;
- Yandex Maps JavaScript API 2.1 для онлайн-карты заказов и маршрута рекомендаций, Tiles API и MapLibre для офлайн-подложки;
- Яндекс Метрика и Sentry.

Точные версии зависимостей и команды смотрите в [`package.json`](../package.json).

## Основные маршруты

| Маршрут                       | Экран                        |
| ----------------------------- | ---------------------------- |
| `/auth`, `/registration`      | Вход и восстановление пароля |
| `/initial`                    | Стартовый экран              |
| `/list_orders`, `/map_orders` | Список и карта заказов       |
| `/price`                      | Расчёт                       |
| `/graph`                      | График работы                |
| `/statistics`                 | Статистика                   |
| `/settings`                   | Настройки                    |
| `/feedback`                   | Предложения                  |

## Карта репозитория

- [`pages/`](../pages) — маршруты и тонкие page-обёртки. Тесты страниц находятся в [`tests/pages/`](../tests/pages), чтобы Next.js не принимал их за маршруты.
- [`widgets/`](../widgets) — экраны и крупные композиции.
- [`features/`](../features) — пользовательские действия и сценарии.
- [`entities/`](../entities) — доменные данные, API-адаптеры и нормализация.
- [`shared/api/`](../shared/api) — общий HTTP-транспорт, конфигурация и адреса API.
- [`shared/ui/`](../shared/ui), [`shared/styles/`](../shared/styles) — повторно используемые элементы и темы.
- [`styles/`](../styles) — существующие глобальные и экранные SCSS-стили.
- [`public/`](../public) — статические файлы, service worker и ресурсы офлайн-карты.

Точка подключения темы, глобальных стилей и интеграций — [`pages/_app.tsx`](../pages/_app.tsx); события Метрики — [`components/analytics.ts`](../components/analytics.ts). Договорённости по изменениям см. в [`AGENTS.md`](../AGENTS.md).

## Открытые задачи следующего этапа

- [x] Завершить логику нескольких заказов по одному адресу: сайт и приложение
      объединяют заказы по координатам и показывают отдельную групповую метку со
      счётчиком, белым контуром, тематической тенью и плашкой статусов. Время у групповой метки
      не показывается; нажатие открывает компактный список
      группы, затем одну выбранную карточку с возвратом к списку. Демо-аккаунт
      содержит группы для «Активные», «Мои» и «У других», включая три заказа на
      одной точке в «Мои» и пять в «У других». Метка показывает не больше трёх цветных точек и
      счётчик скрытых; остаётся ручной smoke на сайте, Android и iOS.
- [x] Поддержать адрес без готового значения улицы: Laravel API формирует `addr`
      из `street` и `home`, а клиенты используют готовое значение без повторного
      разбора населённого пункта.
- [x] Показывать незавершённые заказы за вчера и сегодня: окно задаёт Laravel API,
      сайт и приложение не отбрасывают полученную выдачу и сохраняют её офлайн.
- [x] Ограничить вход, SSO и восстановление пароля пользователям без доступа к
      модулю курьеров; реализация выполнена руководителем на стороне Laravel API.
- [x] ИИ-рекомендации синхронизированы с приложением и Laravel API. Настройка
      `ai_recommend` по умолчанию выключена; при включении доступны кнопки
      «Помочь с выбором» и «Подробнее», маршрут с нумерованными остановками,
      зелёные отметки взятых заказов и единые состояния пустого результата и
      технической ошибки. Настройка `map_hints` отдельно управляет круглыми
      подсказками заказов за границами карты и по умолчанию включена.
- [x] Реализовать доработки настроек и карты по результатам видео коллеги от
      22.09.2026: применение формата подписей и размера маркеров, читаемость
      вариантов оформления в обеих темах, фильтр статусов и сброс настроек.
      Шрифт ограничен диапазоном 10–26; цвет курьера в «У других» берётся из API,
      в остальных категориях сохраняется приоритет цвета статуса. Наличие
      реализации не означает повторный ручной smoke всех платформ.
- [ ] Повторно проверить эти сценарии сайта после обновления зависимостей,
      отдельно от ранее проведённой проверки приложения. Зафиксировать сборку,
      окружение и проверенные сценарии в журнале, не отмечая весь release-smoke
      по результатам unit-тестов.
- [ ] Отдельно согласовать необходимость автоматического масштаба по заказам;
      реализованные настройки и метки не считать подтверждением этого решения.
- [ ] Разобрать задержки скачивания города на локальном backend. Исправленный
      env `preview:offline` не устраняет отдельный 12-секундный лимит проверки

- [ ] Изучить отзывы курьеров, согласовать требования и реализовать только
      подтверждённые доработки.
- [ ] После оставшихся функций обновить тесты и провести итоговую проверку
