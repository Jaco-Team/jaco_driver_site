# Документация курьерского сайта

Здесь хранится рабочая документация `jaco_driver_site`. Корневой [README](../README.md) — краткий вход в проект, а [AGENTS.md](../AGENTS.md) остаётся в корне, чтобы инструкции для инструментов обнаруживались автоматически.

## Проект и разработка

- [Обзор проекта](./project-overview.md) — назначение, стек, маршруты, карта репозитория и открытые задачи.
- [Локальная разработка](./development.md) — запуск, переменные окружения, локальный API и офлайн-preview.
- [Архитектура и API](./architecture.md) — слои, авторизация, контракты и размещение типов.
- [Дизайн и интерфейс](./design.md) — темы, палитра и правила оформления.

## Карта и офлайн-режим

- [Карты](./maps.md) — онлайн-карта API 2.1, офлайн-подложка, ключи и проверка перед выпуском.
- [Офлайн-режим](./offline.md) — данные, доступность экранов, восстановление сети и ограничения.

## Проверка и развёртывание

- [Проверки](./testing/README.md) — доступные команды и ручные сценарии.
- [Релизный чек-лист](./testing/release-checklist.md) — что проверить перед выпуском сайта.
- [Docker](./docker.md) — локальный и production-запуск.

Документация описывает текущее состояние кода, а не обещает, что каждый сценарий уже прошёл проверку на всех устройствах. При изменении контракта или поведения обновляйте соответствующий раздел вместе с кодом.
